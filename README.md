# Chenyu Kevin Zhang — Robotics & Embodied AI

A responsive research portfolio for Chenyu “Kevin” Zhang, an HKUST Computer
Science and Engineering undergraduate exploring robotics, embodied AI,
dexterous manipulation, and human–robot interaction.

**Live website:** https://kevin-freshman.github.io/ChenyuZhangPersonalPage/

## Website structure

- `index.html` — page content, semantic structure, search metadata, and social links.
- `styles.css` — responsive visual system, layout, accessibility, and reduced-motion support.
- `script.js` — mobile navigation, active-section highlighting, and current footer year.
- `_config.yml` — GitHub Pages and Jekyll site metadata.

The website is intentionally framework-free: open `index.html` directly or
serve the repository with any static-file server.

## Updating content

Research descriptions, academic information, project summaries, contact details,
and the profile photo are defined in `index.html`. Styles and interactions are
kept separate so the page stays easy to maintain.

GitHub Pages publishes the repository's `main` branch. Updates pushed to that
branch are automatically reflected on the live site after GitHub completes its
deployment.
